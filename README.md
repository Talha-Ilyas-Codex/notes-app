# Notes App

A simple notes application built with HTML, CSS and JavaScript.
It was created for Software Engineering Assignment 01 (Build and Deploy a Small Application).

## Purpose

The app lets a user write short notes, organise them with colours, and find them again quickly.
The same project is used to practise a DevOps workflow: version control with Git, automatic checks with GitHub Actions (CI), and deployment with GitHub Pages.

## Main Features

- Add a new note with a title and text
- Edit an existing note
- Delete a note
- Choose a colour for each note
- Search notes by title or text
- Notes are saved in the browser (localStorage), so they stay after a refresh
- Works on desktop and mobile screens

## Technologies Used

- HTML
- CSS
- JavaScript (no frameworks)
- Git and GitHub
- GitHub Actions (CI)
- GitHub Pages (deployment)

## How to Run Locally

1. Download or clone this repository.
2. Open the `index.html` file in any web browser.
